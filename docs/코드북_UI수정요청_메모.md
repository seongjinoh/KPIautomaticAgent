# 코드북 UI 수정 요청 메모

테스트 중 피드백 기록용. **구현은 별도 요청 시 일괄 진행.**

---

## 1. Lv1 / Lv2 화면 명칭 변경

### 문제
- 코드북에서 사용자에게 `Lv1`, `Lv2`로만 보이면 업무 용어와 안 맞음.

### 수정 방향
- **Lv1** 표시명 → **Category**
- **Lv2** 표시명 → **지표Seg**
- 대상: 탭/카드 제목, 버튼(`Lv1 추가` 등), 안내 문구, 팝업 라벨 등 **UI 표기**
- 내부 코드·DB 컬럼(`code_lv1`, `lv1_code` 등)은 유지해도 됨 (표시명만 변경)

---

## 2. Lv3 탭 · 지표마스터 탭 삭제 = 실제 삭제 (미사용 제거)

### 문제
- Lv3 / 지표마스터에서 삭제가 안 되거나, 예전처럼 **미사용(`use_yn=N`)만** 처리되는 흐름이 남아 있음.
- Lv1·Lv2는 이미 “연결 없으면 DELETE”로 맞춤. 여기만 어긋남.

### 수정 방향
- **Lv3(공통지표)** · **지표마스터(indicator_code 등)** 삭제:
  - 전역적으로 참조되는 곳 없으면 → **하드 DELETE**
  - 참조 있으면 → 삭제 거부 + 안내 (Lv1/Lv2와 동일 패턴, 409 등)
- **사용/미사용 구분 UI·로직 제거**
  - 미사용 처리 토스트/확인문, `use_yn` 토글·필터·취소선 표시 등 없애기
  - 관련 API도 soft-delete 대신 hard-delete 기준으로 맞추기
- 참조 검사 범위는 구현 시 코드 기준으로 확정 (평가계획, 실적, 배정 등 FK/조인)

---

## 3. Lv3 추가 팝업: 지표명 + AI 마법사 최상단

### 문제
- Lv3 추가 팝업에서 지표명·AI 마법사 위치가 아래쪽에 있어 입력 흐름이 어색함.

### 수정 방향
- 팝업 레이아웃에서 **「지표명」+「AI 마법사」를 가장 상단**으로 이동
- 그 아래 Lv1(Category) / Lv2(지표Seg) 등 나머지 필드

---

## 4. 지표마스터 추가 팝업: Lv3 검색 가능

### 문제
- 지표마스터 추가 시 Lv3가 **드롭다운만** 있어 항목이 많아지면 고르기 어려움.

### 수정 방향
- Lv3 선택을 **검색 가능한 콤보/타입ahead**로 변경 (코드·이름 검색)
- 키보드 입력으로 필터링 후 선택

---

## 5. Lv3 추가 팝업: Lv1·Lv2도 검색 + 렉 방지

### 문제
- Lv3 추가 팝업의 Lv1/Lv2도 드롭다운만이면 불편.
- 예전에 검색/필터 구현 시 **렉(성능 문제)** 이 있었음.

### 수정 방향
- Lv1(Category), Lv2(지표Seg)도 **검색 가능한 선택 UI**
- 성능 주의:
  - 입력마다 과도한 리렌더/전체 리스트 재계산 피하기
  - debounce / 로컬 필터 / 리스트 가상화 등 기존 렉 원인 재발 방지
  - (필요 시) `startTransition` 등 가벼운 업데이트 패턴 검토

---

## 6. 코드북 목록 정렬 버튼

### 문제
- 코드북 목록에 정렬 UI가 없어, 행이 많아지면 원하는 순서로 보기 어려움.
- **연도별 평가배치** 화면에는 이미 정렬 버튼이 있음 → 코드북에도 동일 UX가 필요.

### 수정 방향
- 코드북(관련 탭/테이블)에 **연도별 평가배치와 같은 방식의 정렬 버튼** 추가
- 구현 시 평가배치 쪽 정렬 패턴(컬럼 클릭/토글, 오름·내림차순 등)을 참고해 맞춤
- 대상 컬럼·탭 범위는 구현 시 UI 기준으로 확정 (Category / 지표Seg / Lv3 / 지표마스터 등)

---

## 7. 가공식 추가 팝업: 피연산자 한글 입력 불가

### 문제
- 가공식 추가 팝업에서 **피연산자 이름**을 한글로 입력해도 입력이 반영되지 않음 (글자가 안 들어가거나 IME 조합이 깨짐).

### 수정 방향
- 피연산자 이름 입력 필드의 한글(IME) 입력 버그 수정
- 흔한 원인 점검: `onKeyDown`에서 키 차단, controlled input + 매 키마다 state 덮어쓰기, `value`를 영문/코드만 허용하는 필터, composition 이벤트 미처리 등
- 한글·영문 모두 정상 입력·수정 가능하게

---

## 8. 연도별 평가배치 팝업: 숫자 포맷 · 기본값 · 필드 제거

### 문제 / 요청
- 연도별 평가배치 팝업의 숫자 입력이 **자릿수(콤마) 표시**가 없음.
- 지표 상한·하한·승수·조정구간·조정승수에 **디폴트값이 비어 있음**.
- **수집방식**, **Ownership부서** 필드가 아직 남아 있음 → UI뿐 아니라 **체계(스키마/API/저장 로직)에서도 제거** 원함.
- 아래 **달성률 산정 설정** 구간의 숫자도 자릿수(콤마) 표시 필요.

### 수정 방향
1. **숫자 자릿수 표시(콤마)**  
   - 평가배치 팝업 내 관련 숫자 필드  
   - 달성률 산정 설정 구간의 숫자들도 동일하게  
   - 입력/편집 시 IME·커서·파싱(저장 시 콤마 제거) 깨지지 않게
2. **디폴트값 기재** (신규/빈 값일 때)
   - 지표 상한: **150%**
   - 지표 하한: **40%**
   - 승수: **1**
   - 조정구간: **120%**
   - 조정승수: **0.1**
3. **수집방식 · Ownership부서 제거**
   - UI(팝업/폼/테이블 컬럼)에서 삭제
   - **프론트만이 아니라** DB 컬럼·API 입출력·저장/조회/엑셀 등 **체계 전반에서 제거** (마이그레이션·호환은 구현 시 정리)
